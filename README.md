# 生活小助手 · Daily Hub

自用个人效率工具，当前为可运行的框架预览版。

## 模块

- 番茄时钟：专注 / 短休 / 长休，时长可调，记录今日与累计完成数
- 课程表：按周一到周日展示，支持 1-18 周周期、单双周、开学日期与真实日期联动、只看本周、高亮今天
- 日程表：月历视图，按天添加、编辑、删除安排
- 待办事项：优先级、截止日期、完成状态、筛选
- 备忘录：本地笔记，支持搜索与自动保存

## 技术

- 纯 HTML + CSS + JavaScript，无构建步骤
- 数据保存在浏览器 localStorage，可随时导出 / 导入 JSON 备份
- PWA 支持：可安装为桌面 / 手机应用，离线可用

## 运行

直接用浏览器打开 `index.html`，或在项目目录启动静态服务器后访问。

## 手机访问（同一 Wi-Fi）

1. 双击项目目录里的 `start-server.ps1`（首次运行如被拦截，右键“使用 PowerShell 运行”即可）。
2. 终端会显示类似 `http://192.168.x.x:8770/` 的地址。
3. 手机连接同一个 Wi-Fi，在浏览器打开这个地址。
4. 以后电脑开机后想再访问，重复第 1 步即可。

## 安装为应用（PWA）

### Windows（Edge / Chrome）

1. 打开 http://127.0.0.1:8770/
2. 点击地址栏右侧的“安装”图标（或菜单 → 应用 → 将此站点作为应用安装）
3. 安装后可从开始菜单、桌面快捷方式或任务栏打开独立窗口
4. 打开后进入“总览”，顶部的“今日课程”面板会直接列出当天课程、时间与教室

### 手机（Android / iPhone）

- Android Chrome：菜单 → 添加到主屏幕
- iPhone Safari：分享 → 添加到主屏幕

说明：PWA 安装后是独立窗口应用；Windows 11 小组件面板或安卓桌面小组件这类系统级桌面卡片，PWA 本身不支持。要看当天课程，安装后打开应用即可，总览第一屏就是今日课程。

## 课程表数据结构

```json
{
  "semesterStart": "2026-08-10",
  "courses": [
    {
      "day": 0,
      "start": 8,
      "duration": 2,
      "title": "高等数学",
      "location": "A101",
      "color": "#a34a35",
      "weekStart": 1,
      "weekEnd": 18,
      "weekPattern": "every"
    }
  ]
}
```

`weekPattern` 支持 `every`（每周）、`odd`（单周）、`even`（双周）。当前周次由「开学日期 + 今天真实日期」自动计算。

## 视觉方向

现代简洁 + 暖陶土品牌色：大面积留白、克制的 8px 圆角、浅边框与极淡阴影；桌面端为三列卡片墙与可折叠侧栏，移动端为底部 Tab + “更多”抽屉，编辑弹层统一为底部抽屉样式。
